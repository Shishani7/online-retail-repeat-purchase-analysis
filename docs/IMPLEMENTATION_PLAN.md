# Расширение Online Retail

Задача: подкрепить пункты резюме работающим и проверяемым учебным проектом.

- [ ] Streamlit: показатели продаж, фильтры по периоду и стране, RFM-сегменты и когортный retention.
- [ ] Дизайн A/B-теста CRM-кампании: гипотеза, группы, основная и контрольные метрики, расчёт выборки и правило решения; без заявления о проведённой реальной кампании.
- [ ] Временная валидация: обучающие целевые окна завершаются до даты следующего прогноза; пересчёт метрик на исходных данных.
- [ ] FastAPI: POST /predict, проверка входных признаков и использование сохранённого pipeline.
- [ ] Docker: воспроизводимый запуск API и дашборда, тесты входных данных и инструкция для демонстрации.

Приёмка: автоматические тесты, проверка приложения Streamlit, HTTP-запросы к API, сборка и запуск контейнеров, опубликованные инструкции и проверяемые результаты обучения.
