# Расширение Online Retail

Задача: подкрепить пункты резюме работающим и проверяемым учебным проектом.

- [x] Streamlit: показатели продаж, фильтры по периоду и стране, RFM-сегменты и когортный retention.
- [x] Дизайн A/B-теста CRM-кампании: гипотеза, группы, основная и контрольные метрики, расчёт выборки и правило решения; без заявления о проведённой реальной кампании.
- [x] Временная валидация: обучающие целевые окна завершаются до даты следующего прогноза; пересчёт метрик на исходных данных.
- [x] FastAPI: POST /predict, проверка входных признаков и использование сохранённого pipeline.
- [x] Docker: воспроизводимый запуск API и дашборда, тесты входных данных и инструкция для демонстрации.

Приёмка: автоматические тесты, проверка приложения Streamlit, HTTP-запросы к API, сборка и запуск контейнеров, опубликованные инструкции и проверяемые результаты обучения.

Реализация находится в коде и воспроизводимых артефактах. Локальные тесты, запуск API и Streamlit, исполнение ноутбука и браузерная проверка выполнены. Проверка контейнеров автоматизирована в GitHub Actions; актуальный результат доступен по ссылке CI в README.
